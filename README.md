# FACE-MASK-DETECTION-USING-CNN
Face Mask Detection using Convolutional Neural Networks (CNN) and TensorFlow.
# OVERVIEW
This project uses a Convolutional Neural Network (CNN) to detect whether a person is wearing a face mask or not.

# TECHNOLOGIES USED
1.Python
2.TensorFlow
3.Keras
4.OpenCV
5.NumPy
6.Matplotlib

# DATASET
Face Mask Dataset from Kaggle

# MODEL PERFORMANCE
  1. Validation Accuracy: 94.21%
  2. Test Accuracy: 92.19%

# WORKFLOW
1.Data Collection
2.Image Preprocessing
3.Label Creation
4.Train-Test Split
5.CNN Model Building
6.Training
7.Evaluation
8.Prediction System

# RESULTS
The CNN model successfully classifies images into:
1.With Mask
2.Without Mask
with over 92% test accuracy.
